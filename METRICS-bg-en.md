# Измерване на използването / Measuring Real Use

**Kiki Innovation & Learning Lab · v1.0 · 16.11.2026**

## Български

**Цел:** да разберем дали ресурсите помагат на хората да учат и прилагат, а не само дали страницата е отваряна.

| Показател | Определение | Начин на събиране | Начална стойност |
| --- | --- | --- | --- |
| Успешно намерен ресурс | Успешни задачи за намиране / всички задачи | Анонимни наблюдения по тестовия протокол | Няма данни |
| Самостоятелно изпълнена задача | Завършени без помощ / всички опитани | Доброволна обратна връзка и учебно наблюдение | Няма данни |
| Полезност | Отговор „полезен“ или „много полезен“ / отговорили | Кратък доброволен въпрос | Няма данни |
| Пречки в навигацията | Брой уникални проблеми, групирани по причина | Анонимни бележки от теста | Няма данни |
| Време до материал | Медиана на минутите до подходящ ресурс | Анонимен тест с доброволци | Няма данни |

**Пилотни цели за проверка:** ≥80% успешно откриване без подсказки; медиана до 4 минути; поне 3 описани подобрения след първия тест. Това са *цели*, не действителни резултати.

**Поверителност:** началната страница не съдържа analytics скрипт или бисквитка за проследяване. Не записвайте IP адреси, потребителски идентификатори, данни от училищни профили или индивидуални оценки в публичното GitHub хранилище. По-нататък може да се обсъди агрегирана аналитика само след проверка на законовите и училищни изисквания.

## English

**Goal:** measure whether learners find and apply resources, not just page views.

| Metric | Definition | Collection | Baseline |
| --- | --- | --- | --- |
| Resource findability | Successful discovery tasks / all attempted tasks | Anonymous observation | No data |
| Independent task completion | Completed without hints / tasks attempted | Voluntary feedback | No data |
| Perceived usefulness | Positive usefulness responses / respondents | Brief optional question | No data |
| Navigation friction | Number of distinct issues grouped by cause | Anonymous test notes | No data |
| Time to useful resource | Median minutes to find an appropriate item | Voluntary usability sessions | No data |

**Pilot goals (not results):** ≥80% findability without hints; median ≤4 minutes; at least three actionable improvements.

**Privacy:** no tracking scripts are embedded in the home page. Do not publish participant identifiers or individual academic performance. Consider aggregate analytics only after an appropriate privacy review.
