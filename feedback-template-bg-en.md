# Обратна връзка / Feedback

**Използвайте този шаблон без имена и лични данни. / Use this template without names or personal information.**

## Български — кратък формуляр

- Роля (по избор): ученик / преподавател / ментор / друго
- Търсех: ______
- Намерих подходящ материал: да / отчасти / не
- Успях да изпълня задачата: да / отчасти / не / не приложимо
- Кое ме затрудни? ______
- Кое ми помогна най-много? ______
- Една конкретна промяна, която предлагам: ______

*Не записвайте имена, имейли, лични истории, лични данни или идентифициращи цитати.*

## English — short feedback form

- Role (optional): student / teacher / mentor / other
- I was looking for: ______
- I found a suitable resource: yes / partly / no
- I could complete the activity: yes / partly / no / not applicable
- What was confusing? ______
- What helped most? ______
- One change I suggest: ______

*Do not include names, emails, private stories, personal data or identifying quotations.*

**Важно / Important:** Това е шаблон в GitHub, а не активна анкета. Не изпраща отговори никъде. / This is a GitHub template, not a live survey; it does not submit responses.
